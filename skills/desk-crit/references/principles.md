# Principles for crits

Seven areas used in crits, the journal and exercises. Use these exact names: **hierarchy, contrast, alignment, rhythm, typography, color, composition**.

## Ranking issues

Impact on the work's purpose decides. Default order when impact is similar:
1. **Hierarchy / composition**: can a viewer get the message and next step?
2. **Contrast / readability**: can they read it at all?
3. **Alignment / rhythm**: does it feel ordered and intentional?
4. **Typography / color details**: polish.

A beginner with a hierarchy problem does not need kerning notes. An advanced designer with solid structure gets polish notes, since that's their real gap.

## 1 Hierarchy

The order in which the eye reads. One thing first, then a clear second and third.
- **Look for:** squint test (blur your eyes; what's left?); count elements fighting for first place; is the most important info the most prominent?
- **Common mistakes:** everything the same size; decorative element louder than message; too many accents; key info (date, price, CTA) buried.
- **Tools:** size, weight, color, contrast, space, position. Use 1–2 at a time.
- **Why it matters:** viewers give a few seconds; if the order is unclear they leave or miss the point.

## 2 Contrast

Difference that creates attention and legibility: value, size, weight, color, density.
- **Look for:** text contrast ratio (≥4.5:1 body, ≥3:1 large text); "polite" differences (16 vs 18px) that read as mistakes; low-contrast text over images or patterns.
- **Common mistakes:** grey-on-grey; timid scale steps; busy backgrounds behind text.
- **Rule of thumb:** if two things differ, make them clearly different; if they don't, make them identical.

## 3 Alignment

Shared edges and axes that make a layout feel intentional.
- **Look for:** number of distinct left edges; centered + left-aligned mixed; elements almost-but-not aligned (off by 2–8px); numbers not right-aligned in tables.
- **Common mistakes:** centering everything (weak edges); inconsistent paddings inside cards; text and image edges unrelated.
- **Test:** draw vertical lines through left edges; fewer lines = calmer.

## 4 Rhythm (spacing)

Consistent, intentional spacing that groups related things (proximity) and separates groups.
- **Look for:** spacing values used (should come from a scale like 4/8/16/24/32/48/64); gap inside groups < gap between groups; vertical rhythm in text (line height).
- **Common mistakes:** equal spacing everywhere (no grouping); random values; labels closer to the wrong field.

## 5 Typography

Type choice, scale, measure, leading, and treatment.
- **Look for:** number of families (1–2 is typical); scale ratio between levels; body size (≥16px web); line length (45–75 characters); line height (1.4–1.6 body, 1.0–1.2 display); orphans; tracking on caps.
- **Common mistakes:** 3+ display fonts; script/novelty fonts for information; all caps paragraphs; tight leading on body; long lines.

## 6 Color

Palette, roles and meaning.
- **Look for:** number of hues; does each color have a role (brand, action, status, neutral)? saturation balance; semantic misuse (red for non-errors); charts with too many hues.
- **Common mistakes:** every element a different color; accent used so often it stops being an accent; pure black on pure white for large areas; colors carrying information without a second cue.
- **Rule of thumb:** 60/30/10 as a starting split (neutral / secondary / accent).

## 7 Composition

How the whole frame is organised: grid, balance, focal point, flow, use of space.
- **Look for:** a grid (columns, margins); visual weight balance; a clear entry point and path; edges and crops; empty space that is purposeful vs leftover.
- **Common mistakes:** everything floating in the middle; elements touching edges without intent; decorative shapes competing with content; no relationship between parts.

## Explaining by level

- **Beginner (level 1–2 in an area):** name the principle in plain words, point at one place, give one rule of thumb. Avoid jargon or define it inline. "Hierarchy, the order the eye reads things in."
- **Intermediate (3):** name the principle, connect cause and effect, suggest a technique with numbers ("try a 1.5 type scale: 16 / 24 / 36").
- **Advanced (4–5):** talk about trade-offs and intent, refer to systems (tokens, grids, rhythm), challenge a decision ("the asymmetry is deliberate, but the right column has no anchor").
