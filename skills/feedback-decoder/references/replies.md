# Reply drafts

Write in the client's language, as the designer, first person. Keep it short: 80–160 words for a normal round. Translate naturally; never word-for-word.

## Structure

1. **Thanks + one specific thing** from their message ("Thanks, the note about the menu on mobile is really useful").
2. **What I'll change**: 2–4 bullets in plain words, no px values unless the client is technical.
3. **One or two questions**: closed or visual ("Would you prefer A (…) or B (…)? I can show both side by side").
4. **What stays** (optional, one line): reassure on what they liked.
5. **Next step**: what they will receive. Do not promise dates or prices; leave `[date]` placeholders.

## Tone variants

**Friendly**: warm, collaborative, a little informal for the culture. Uses "we". Offers variants generously.

**Firm**: same warmth, fewer options, clear boundaries. States the professional recommendation and the reason in one sentence. Use when requests conflict, rounds are running out, or a request would hurt usability. Firm is never cold, sarcastic or defensive.

Never: apologise for the original design, blame the client for vagueness, use jargon ("hierarchy", "kerning") without a plain explanation, or say "as I said before".

## Pushing back on a harmful request

Pattern: acknowledge goal → name the risk in user terms → offer an alternative that meets the goal.
> "I understand you want the page to feel lighter. Making the grey text even paler would make it hard to read on phones in daylight, so instead I'll lighten the background and add more space between sections. That gives the same airy feeling."

## Scope-change message (new request outside the brief)

Friendly:
> "Love the idea of adding online ordering! It goes beyond what we planned for this project (the brief covers the homepage and menu pages), so I'd suggest we finish the current round first and then I'll send you a short separate estimate for the ordering flow. Does that work for you?"

Firm:
> "Online ordering is a new piece of work outside our current brief. I'm happy to do it, and I'll send a separate estimate for it. For this round I'll focus on the changes above so we stay on schedule."

## Round-limit message (rounds used ≥ agreed)

Friendly:
> "Quick heads-up: this is the last of the [N] revision rounds we agreed. Let's make it count. Could you gather any remaining comments from your team into this round? If we need more after this, additional rounds are billed separately as in our agreement."

Firm:
> "We've now used the [N] revision rounds included in the project. I'll make the changes listed above as the final included round. Further changes are possible as additional rounds; I'll send the details if needed."

Placeholders like `[N]` and `[date]` stay as placeholders. Never insert prices or amounts.

## Language notes

- **Russian**: use «вы» (lowercase unless very formal), avoid канцелярит («осуществить», «в рамках данного»). Friendly ≠ familiar; no «ок» in firm variant. Example opening: «Спасибо за подробные комментарии! Особенно полезно замечание про цифры.»
- **German**: "Sie" by default unless the client used "du". Direct is fine; firm variant can be very concise.
- **Spanish**: "usted" for corporate, "tú" if the client used it. Warm closings ("¡Un saludo!").
- **English**: avoid over-apologising ("so sorry"); "Happy to…" works well for friendly.
- Mirror the client's formality and length. A two-line message deserves a short reply.

## Quick mode

One reply (friendly), 3–5 sentences.
